The page optimisation template

To increase impressions

  1. Assign one primary intent to one page.
  2. Add one prominent section for each meaningful secondary query cluster.
  3. Answer the use case, audience, workflow, and differentiation questions in the body.
  4. Add five to ten contextual internal links from genuinely related guides.
  5. Link specialist pages from the correct hub page.
  6. Check indexability, canonical URL, crawlability, and mobile rendering.

To increase clicks

  1. Use a concise, specific title that matches the query intent.
  2. Write a unique meta description with audience, benefit, and a clear next step.
  3. Make the first paragraph confirm that the searcher has reached the correct page.
  4. Show proof, screenshots, and clearly verified capabilities.
  5. Remove vague, exaggerated, or unsupported claims that weaken trust.
  6. Do not expect snippet edits alone to compensate for weak page relevance or position.

30-day execution order

  1. Days 1–3: Confirm page ownership in Search Console for the top commercial queries. Record current title, H1, meta description, clicks, impressions, CTR, and position.
  2. Days 4–10: Optimise homepage, Studio Operations, Studio Scheduling, Production Management, and the Equipment hub.
  3. Days 11–17: Optimise Inventory, Film and Video, Post-Production, Invoicing, and Media Asset Management.
  4. Days 18–23: Strengthen Photography, Recording Studio, and Podcast pages, then add supporting internal links.
  5. Days 24–27: Improve the film equipment list for informational traffic. Review competitor-alternative pages without chasing brand-only searches.
  6. Days 28–30: Run URL Inspection on changed URLs, document the publish date, and create a 28-day comparison dashboard.

Measurement rules

  • Compare the same query and the same target URL before and after the change.
  • Primary success: the intended URL becomes the leading page and moves from positions 10–13 into the top 10.
  • Secondary success: impressions expand across relevant variants and clicks increase without relying on irrelevant queries.
  • Review after 14 days for indexing and page ownership, then after 28 days for ranking, impressions, CTR, and clicks.
  • Do not combine page-level impression totals and treat them as unique searches when multiple site URLs can appear together.
