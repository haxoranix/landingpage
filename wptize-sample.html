What counts as one task?

1 task = 1 landing page up to 7 sections, responsive, basic animations, and form integration.

We break a 5-page business site into 8 sequential tasks to maintain the 48–72 hour delivery rhythm:

  1. WordPress setup + coming soon page
  2. Header, footer + global styles
  3. Home page
  4. About page
  5. Services page
  6. Blog listing + single post template
  7. Contact page + forms + standard functionality
  8. On-page SEO setup for all 5 pages

1 task = 1 URL. Includes meta title, description, H1–H3 structure, OG tags, internal links, image alt text, and schema setup.

1 task = up to 5 blog posts uploaded and formatted, or content updates across up to 5 existing pages.

1 task = one maintenance pass: WordPress core, theme and plugin updates, backup check, plus minor bug fixes within scope.

1 task = 1 standard ACF flexible module such as Testimonials, Team Grid, FAQ, or Pricing Table. Complex custom PHP logic is not included.

Quoted separately / outside standard subscription scope

Complex custom development, full eCommerce builds, multilingual / multisite / multivendor systems, and premium theme or plugin licenses.
